================================================================================
XML internal declarations cannot contain a parameter reference
:error
:language(xml)
================================================================================
<!DOCTYPE root [<!ENTITY % model "EMPTY"> <!ELEMENT root %model;> ]><root/>
--------------------------------------------------------------------------------

================================================================================
XML internal entity values cannot contain a parameter reference
:error
:language(xml)
================================================================================
<!DOCTYPE root [<!ENTITY % word "text"> <!ENTITY text "%word;"> ]><root/>
--------------------------------------------------------------------------------
